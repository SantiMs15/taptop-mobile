# Carrito de compras — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carrito con página `/carrito`, página de datos de envío para carrito y "Comprar ahora", un solo pago en Wompi y correo del pedido aprobado a `servicioalcliente@taptopmobile.com`.

**Architecture:** El carrito vive en una cookie (`tt_cart`) con `[sku, color, qty]`. El servidor lo valida y le pone precio desde el catálogo en cada carga. Al pagar, la página `/pago/envio` guarda una foto del pedido (líneas, totales, datos de envío) en `app/logs/wompi-orders.json` y redirige a Wompi. El webhook y `/pago/resultado` leen esa foto, comparan el monto y envían el correo una sola vez cuando el pago queda APPROVED.

**Tech Stack:** PHP 8.3 sin framework ni base de datos; JS sin dependencias; SMTP propio mínimo (sin Composer).

**Spec:** `docs/superpowers/specs/2026-10-22-carrito-design.md`

## Review Focus

1. **Cookie alterada o basura** (JSON roto, sku inexistente, qty 99, 50 líneas, color con HTML) → carrito vacío o recortado a lo válido, sin aviso PHP ni error 500. Test en Task 1.
2. **Webhook y `/pago/resultado` llegan casi a la vez** → el correo sale una sola vez. Test en Task 6.

  - `cart_set_qty(array $lines, int $index, int $qty): array` (qty 0 quita la línea).
  - `cart_priced(array $lines): array{lines: list<array{index:int, sku:string, color:?string, qty:int, available:bool, slug:?string, name:string, label:string, image:?string, url:?string, cash:int, gw:int, line_cash:int, line_gw:int}>, cash: int, gateway: int, count: int, has_unavailable: bool, shipping: array}` — líneas cuyo sku no existe se omiten; las agotadas van con `available=false` y no suman. `count` = suma de qty disponibles. `shipping = shipping_info(cash, gateway)`.
  - `cart_count(): int` (para el ícono; no carga precios si la cookie está vacía).
  - `wa_message_cart(array $priced): string` con este formato exacto (línea por producto disponible, precio = `line_cash`):
